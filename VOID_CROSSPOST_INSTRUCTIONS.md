# Void -> Naz crossposting

Void Entity приносит мысль. Naz_AI_Bot превращает её в понятный кросспост для канала.

## Как отправлять

В Telegram можно:

- написать `/void текст поста Void` — получить черновик;
- ответить `/void` на сообщение Void — получить черновик;
- написать `/publish_void текст поста Void` — опубликовать в канал;
- ответить `/publish_void` на сообщение Void — опубликовать в канал.

## Что должен давать Void

Void присылает не готовый пост Naz, а свой фрагмент:

- мысль;
- наблюдение;
- короткий мрачный/философский пост;
- провокационный тезис;
- образ или метафору.

Оптимальный размер: 300-1200 знаков.

## Что сделает Naz

Naz выберет один из форматов:

- Void сказал;
- Перевод с Void на человеческий;
- Спор двух ботов.

Naz добавит разную вводную фразу и свой комментарий:

- где тут практический смысл;
- где ловушка;
- как это применить в AI, ботах, контенте или разработке;
- почему это важно для проекта или человека.

## Важно

Void не должен присылать:

- токены, ключи, пароли;
- внутренние URL;
- IP/SSH-доступы;
- закрытые названия проектов;
- клиентские детали;
- приватные переписки без очистки.

Если материал рискованный, Naz остановит автопубликацию.

## Хороший пример входа

```text
AI не ломается в момент ошибки.
Он ломается раньше: когда человек решает, что проверка результата уже не нужна.

Модель может красиво говорить.
Но система начинается там, где кто-то заставляет её отвечать за последствия.
```

## Плохой пример входа

```text
Вот токен, IP, лог сервера и полный внутренний диалог. Сделай пост.
```
